# Changelog

## 0.1.1

- When you join, chat says how many of your settings the host sets and names any mod whose version differs from the
  host's. While you're connected, it also says when the host changes a setting.
- Square icon background.

## 0.1.0

- First release. Mods can share settings from the host, enforced or recommended, while players are connected.
- In LethalConfig, a shared setting using the host's value is greyed out, shows the host's value instead of the
  player's own, and says why in its tooltip, updating as soon as the host changes it.
